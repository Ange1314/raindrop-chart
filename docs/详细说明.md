## 30 秒跑起来

### 第 1 步：确认有没有 Python

打开终端（Windows 按 `Win+R` 输入 `cmd` 回车；macOS 打开「终端」），输入：

```bash
python --version
```

- 显示 `Python 3.8.x` 或更高 → 跳到第 2 步
- 显示 `Python 2.x` → 试 `python3 --version`
- 报错「不是内部或外部命令」/ `command not found` → **装一个 Python**

**怎么装 Python：**

| 系统 | 做法 |
|---|---|
| Windows | 去 [python.org/downloads](https://www.python.org/downloads/) 下载安装包，**安装第一屏必须勾选 `Add python.exe to PATH`**，然后一路 Next |
| macOS | 终端执行 `brew install python3`；没装 Homebrew 就去 python.org 下安装包 |
| Linux | `sudo apt install python3`（Debian/Ubuntu）或 `sudo dnf install python3`（Fedora） |

装完关掉终端再重开，重新验证一次版本号。

### 第 2 步：拿到代码

**会用 git 的话：**

```bash
git clone https://github.com/Ange1314/raindrop-chart.git
cd raindrop-chart
```

**不会 git 的话：** 在仓库页面点绿色的 `Code` → `Download ZIP`，解压到一个你找得到的文件夹（比如桌面）。**别在压缩包里直接双击运行**，要先解压。

> 完全不想碰命令行？那也要先装 Python —— **目前还没有免安装版**（自带运行时的 zip 还没做）。
> 装完 Python 之后，日常就只有双击 `双击启动雨滴图.vbs` 这一件事。

### 第 3 步：启动

Windows 上，启动就是双击这一个文件：

**`双击启动雨滴图.vbs`**

没有别的入口，不用选。

服务在后台起来，浏览器自己打开 `http://127.0.0.1:7788/`。**没有黑窗口**你要关，
也不会有「该点哪个」的问题 —— 入口只有一个。

（如果系统问「是否允许 Python 访问网络」，可以拒绝 —— 它只在本机 `127.0.0.1` 上通信。）

**出问题怎么办：** 会弹一个窗告诉你原因；完整报错写在 `data/运行日志.txt`。

> **只想要图，就到此为止。** 想让 AI 也能读这套数据，再多一步：双击 `连接Buddy.vbs`，
> 然后重开 WorkBuddy —— 详见下面 [MCP 接口](#mcp-接口可选进阶)。

**macOS / Linux：** 在终端里进入这个文件夹，执行：

```bash
chmod +x start.sh    # 只需要第一次
./start.sh
```

浏览器会自动打开。没自动开的话，把终端里显示的地址（类似 `http://127.0.0.1:7788/`）复制到浏览器。

用 `start.sh` 启动时终端里会打出来这一段：

```
============================================================
  Raindrop Chart 已就绪

  地址    http://127.0.0.1:7788/
  ...
============================================================
```

**要停止：** Windows 在任务管理器结束 `python.exe`（或 `pythonw.exe`）；
macOS / Linux 在那个终端按 `Ctrl+C`。

## 怎么用

### 首页：每个数据源一颗珠子

打开就是下面这个样子。一颗珠子 = 一个数据源（一个 CSV 文件）。

![首页](docs/img/01-home.png)

珠子大小按数据量算，所以你一眼能看出哪个库最大。

### 点进去：看到分组

![点开一层](docs/img/02-drill.png)

```
外层大圆  =  一个分组
圆周珠子  =  组里的条目
珠子大小  =  value 的数值
```

**再点一颗珠子，继续往里钻。**

![第三层](docs/img/03-into.png)

顶部那行字是面包屑，点任意一级能跳回去：

```
Raindrop Chart › 产品线.csv › 智能硬件
```

### 操作方式

| 操作 | 效果 |
|---|---|
| **单击珠子** | 往里钻一层 |
| **点面包屑** | 跳回上面某一层 |
| **鼠标悬停** | 看这颗珠子的名称和具体数值 |
| **按住珠子拖动** | 临时把它挪开看被挡住的圆，**松手会自己弹回去**，不改变布局 |
| **右键** | 打开菜单（内容见下） |
| **Esc** | 收起所有下级，只留当前这一层 |
| **浏览器后退键 / 侧键 / `Alt+←`** | 返回上一层。层级变化会记进浏览历史，用浏览器自己的后退就行 |
| **左上角「已连接」** | 表示**连上了本地服务**（不是联网）。直接双击 html 打开时会显示「离线」，并且只画 `data.js` 里的演示数据 |
| **顶部搜索框** | 输入关键词，回车跳到那颗珠子。**标题、文件名、对话正文都会搜**，命中处会显示一小段原文 |
| **右上角「树图 / 雨图」** | 切换视图 |

**右键菜单里有什么：**

- 点在珠子上的时候：下雨（刷新）／ 固定雨滴 ／ 展开下级 ／ 复制名称 ／ 复制路径
- 点在空白处的时候：下雨 ／ 换主题（六套配色）
- 不管点在哪，最后一段固定是：`WorkBuddy · 已连接/未连接`、`新增数据源 · CSV`、`新增数据源 · 文件夹`

固定的几项位置不会变，靠肌肉记忆点就行。

> 没有缩放功能。图会按窗口大小自动调整比例，不需要手动缩放。窗口拉大，图就跟着变大。

## 锁定：让 AI 读不到某几项

左侧列表每一行末尾有两个图标，管两件不同的事：

| 图标 | 干什么 | 鼠标悬停时写着 |
|---|---|---|
| 👁 眼睛 | 在雨滴图中隐藏这一层（你自己也看不见它） | 隐藏：在雨滴图中隐藏 |
| 🔒 锁 | **禁止 AI 搜索和操作，你自己照常用** | 锁定：禁止 AI 搜索和操作，但你可以正常使用 |

**锁的语义就是 PS 的图层锁**：行还在、数字还在、照样点得开，只有那个图标变成**红色实心**。不会复制出一行，也不会把东西藏起来。

- 锁只对「外部读取」生效：MCP 接口和搜索都读不到它，**但你自己在页面上看完全不受影响**
- 表头会统计：`已锁定 2 项 · 禁止 AI 读取`。一项都没锁的时候这行字不显示
- **每一项单独设锁**，不是全库一把；每设一次要输密码
- 密码**不存在你的硬盘上**。本地只留 `salt`（随机盐）和 `check`（校验值），算法是 PBKDF2-SHA256、60 万轮 —— 拿到文件也反推不出密码
- **忘记密码只能重置，而重置不需要密码**（密钥就在硬盘上）。所以别说「忘了就解不开」，那是假的

## 换成你自己的数据

有两条路，**推荐第一条**。

### 方法 1：把 CSV 放进 data/sources/ 文件夹（最省事）

1. 把你的 `.csv` 文件复制到 `data/sources/`（第一次启动时程序会自己建好）
2. 刷新浏览器页面

就这样，不用重启程序。新的一颗珠子会出现在首页。

**想删掉？** 把 `data/sources/` 里对应的文件删掉，刷新页面，珠子就消失了。

### 方法 2：在网页里导入

在画布上点右键，底部有两个入口：

- **`新增数据源 · CSV`** — 选一个 `.csv`，变成一个库
- **`新增数据源 · 文件夹`** — 选一个文件夹，把里面的**目录结构**（不是文件内容，只有路径和文件名）画成一张图，适合看项目目录长什么样

## 数据格式

**三列，第一行必须是表头，文件名用 `.csv`，编码必须是 UTF-8。**

```csv
parent,name,value
,智能硬件,
,软件平台,
智能硬件,结构设计,42
智能硬件,电路板,38
软件平台,前端,45
软件平台,后端,52
```

| 列 | 含义 |
|---|---|
| `parent` | 所属分组。**留空 = 顶级分组** |
| `name` | 这一项的名字（图上显示的就是它） |
| `value` | 决定珠子多大多远。留空当 1 算 |

### 想要更多层级？

`parent` 里用 `/` 分隔写完整路径就行，想几层写几层：

```csv
parent,name,value
,公司,
公司/技术部,后端,50
公司/技术部,前端,45
公司/市场部,投放,30
```

中间层（「技术部」这种）**可以不用单独写一行**，程序会自动补出来。

### Excel 怎么存成 UTF-8

Excel 里「另存为」→ 文件类型选 **「CSV UTF-8（逗号分隔）」**。

选成普通的「CSV（逗号分隔）」在中文 Windows 上会存成 GBK，读出来是乱码。

### 现成的例子

`examples/` 文件夹里有两份可以直接拿来改：

- `examples/hello.csv` — 三层结构，最小示例，用来验证图没坏
- `examples/orders.csv` — 一份电商订单履约的层级数据，比较像真实场景

复制到 `data/sources/` 里就能在图上看到。

## 读 WorkBuddy 会话（可选）

如果你电脑上装了 [WorkBuddy](https://www.workbuddy.cn/)，这个程序会自动读它的会话记录（`~/.workbuddy/projects/` 下的 `.jsonl` 文件），把你的对话和工具调用画成图 —— 能看出自己在哪个项目上花了多少步、哪些文件被反复改。

**没装 WorkBuddy 完全不影响使用**，只是首页少了「WorkBuddy 会话」那颗珠子，用 CSV 就够了。

几点说明：

- 只**读**，不写、不改、不删你的会话记录
- 不会上传任何东西
- 想让它读别的会话，启动前设置环境变量 `RD_SESSION=文件路径`

## 常见问题

**Q：解压后文件名变成乱码（`啟動.bat`、`???`）**

用 Windows 自带的「解压到当前文件夹」解旧 zip 时偶发，是压缩包里的编码标记没被认。
换 **7-Zip** 或 **Bandizip** 解压就好，或者干脆 `git clone`。

**Q：点了 `双击启动雨滴图.vbs` 什么都没发生**

先看它有没有弹窗 —— 弹窗里写的就是原因，最常见的是「没找到 Python」。
弹窗也没出现的话，打开 `data/运行日志.txt`，最后几十行就是真实报错。
还是想看命令行输出，自己开一个终端敲这一行（等价于双击它）：

```bash
python app/live_server.py
```

**Q：浏览器打开是空白 / 一直转圈**

先看终端窗口里有没有报错。如果终端显示「已就绪」但网页打不开，可能是端口被别的程序占了 —— 程序会自动往后找端口（7788 → 7789 → 7790…），**以终端里实际显示的地址为准**，不要用旧地址。

**Q：中文显示成乱码**

CSV 不是 UTF-8。用 Excel 重存一次，选「CSV UTF-8」。

**Q：图上的珠子挤在一起 / 重叠**

这是目前已知问题，靠固定摆位规避，没有通用的防重叠算法。数据条目特别多的时候会比较明显。可以试着把它拆成几个更小的 CSV。

**Q：名字太长变成「订单履约 · ...」**

有截断但没做自适应缩放。把 `name` 写短一点可以绕开。

**Q：关掉网页了，但后台还有进程**

叉掉网页不会停掉后台进程。Windows 在任务管理器里结束 `python.exe` / `pythonw.exe`；macOS/Linux 回到终端按 `Ctrl+C`。

**Q：能不能放到服务器上给别人看？**

不建议。这程序是给单机用的：它读的是本机文件、监听 `127.0.0.1`、没有做任何鉴权。要分享，把 CSV 和截图发给对方，让对方自己跑。

## 文件说明

```
raindrop-chart/
├── 双击启动雨滴图.vbs       ← 双击这个（Windows，唯一的入口，不弹窗口）
├── start.sh           ← macOS / Linux 用这个
├── 连接Buddy.vbs        ← 想让 AI 能读这套数据，再双击这个
├── icon.ico           ← 桌面图标（多尺寸，透明背景）
│
├── app/               【软件本体】升级时整目录替换，别往里放手写的东西
│   ├── live_server.py 主程序：起本地服务 + 解析数据 + 提供 API
│   ├── ring.html      画布页面（自包含，不引外部资源）
│   ├── datasource.py  数据源适配层：WorkBuddy 会话 / CSV / 文件夹结构
│   ├── paths.py       目录分区：哪边是程序、哪边是你的数据
│   ├── lockbox.py     锁定：密码校验值、哪些节点被锁（不含密码本体）
│   ├── mcp_server.py  MCP 接口（可选，见下）
│   ├── register_mcp.py 注册用的实现（被 连接Buddy.vbs 调用，不直接双击）
│   ├── weights.py     权重口径：珠子多大、怎么算（改视觉比例看这里）
│   ├── data.js        离线演示数据（不起服务直接打开 ring.html 时用）
│   └── examples/      自带示例 CSV（属于程序，不是你的数据）
│
├── data/              【软件的信息】第一次启动自动建；升级、换版本都不动它
│   └── sources/       你放自己 CSV 的地方（内容不进版本库）
│
├── README.md / README.en.md      介绍页（只讲三件事和怎么用）
├── LICENSE
└── docs/
    ├── 详细说明.md               本文
    └── img/                      截图
```

**为什么分成 `app/` 和 `data/`：**

因为这两样东西的**寿命不一样**。程序会升级、会被整个替换；你的数据不能跟着换一次就没了。
分开之后：

- 想换个版本 → 只换 `app/`，`data/` 原地不动，库还在
- 想备份 → 只拷 `data/`，那是唯一有你痕迹的地方
- 想回到「第一次打开」 → 把 `data/` 删掉，程序下次启动会重新建一个空的
- 想发给别人 → 只发 `app/`，你的数据一份都带不出去

数据目录的位置可以用环境变量 `RD_USER_DIR` 改（比如放到同步盘里）。
老版本那种「代码和数据混在一个文件夹」的布局也照样认，升级不会找不到自己的库。

改代码前值得知道的几条：

- **只依赖 Python 标准库**，没有任何 `pip install` 步骤
- `ring.html` 的样式和脚本**全部内联**，只有一个本地依赖 `data.js`（离线演示数据）。
  不引任何 CDN、外部字体或第三方 CSS/JS，所以断网也能打开
- 数据源在 `datasource.py` 里，加一个新类型 = 写一个 `Source` 子类并注册
- 版本号的唯一来源是 `live_server.py` 里的 `VERSION`

### MCP 接口（可选，进阶）

`mcp_server.py` 让 AI（比如 WorkBuddy）能直接读这套工作流数据，问「我这周在哪些项目上花了多少步」这类问题。

**不需要这个功能就完全不用管它**，不影响看图。

#### 要手动点一次 —— 只有这一次

**解压完不会自动连上。** AI 客户端不可能自己去硬盘上发现这个文件夹：它需要一条
「用哪个解释器、跑哪个文件」的配置。这一步没法省，但只需要做一次。

双击 **`连接Buddy.vbs`**（不弹黑窗口，只在结束时弹一个结果框）：

1. 双击 `连接Buddy.vbs` —— 包放在哪个文件夹都行，**不用你填路径**，脚本会算出自己的绝对路径
2. **完全退出并重开 WorkBuddy**（工具清单只在会话启动时读，不重开不生效）
3. 打开连接器管理页，找到 `raindrop-workflow`，点「信任」

之后**不用再点它**：每次 WorkBuddy 启动会按配置自己去拉起这个服务（`app/live_server.py --mcp`）。
就算网页没开，AI 照样能读数据 —— 只有「让雨滴图跳到某一层」需要网页开着。

脚本会先看这台机器装了哪些客户端，**只改已经装了的**，没装的一个都不创建：

| 客户端 | 配置文件 |
|---|---|
| WorkBuddy | `~/.workbuddy/mcp.json` |
| Cursor | `~/.cursor/mcp.json` |
| Claude Desktop | Windows `%APPDATA%\Claude\claude_desktop_config.json`；macOS `~/Library/Application Support/Claude/claude_desktop_config.json` |

每个文件都只 merge 一条 `raindrop-workflow`，别的服务器条目一个不碰；改之前先备份成
`<配置>.bak-<时间>`，解析失败就完全不动那个文件。想撤销就把备份改回去。
连了哪几个、跳过了哪几个，都写在 `data/注册结果.txt`。

#### 想手动配（或者你的客户端不是 WorkBuddy）

自己编辑 `~/.workbuddy/mcp.json`，加一段。`args` 里那个路径**取决于你把包解压到哪**：

```json
{
  "mcpServers": {
    "raindrop-workflow": {
      "type": "stdio",
      "command": "python",
      "args": ["<解压位置>/raindrop-chart/app/live_server.py", "--mcp"],
      "timeout": 30000
    }
  }
}
```

> 路径怎么拿：在资源管理器里进到 `app` 文件夹，点一下地址栏，把整条复制下来，
> 后面补 `\live_server.py`。注意 JSON 里反斜杠要写两个（`\\`），或者干脆全用正斜杠 `/`。

它提供三个工具：

| 工具 | 干什么 |
|---|---|
| `workflow_tree` | 输出完整的工作流树 JSON（对话 / 空间两个视角），可裁剪 |
| `workflow_report` | 文字报表：概况、回合列表、最慢步骤、文件谱系、全库总览、检索… |
| `workflow_show` | 让雨滴图跳到指定位置 —— 前提是**网页正开着**，否则它会明确告诉你「雨图没打开」而不假装成功 |

## 常见误解

**「装上就能看到图」** —— 用 CSV 数据源时是的；用 WorkBuddy 会话数据源时，得先装 WorkBuddy 并有会话记录。

**「它能读我的聊天内容」** —— 读的是**元数据**（什么时候、调了什么工具、动了哪些文件），不是聊天正文。

**「AI 能让它干什么」** —— 只能读数据、让它跳转。它**不能**替你改文件、发消息、动你的账号。

## 关于隐私

这个程序的设计前提是：**你的数据不出你的电脑。**

具体到代码层面：

- 服务只监听 `127.0.0.1`（本机回环地址），局域网里的其他机器也访问不到
- 全代码**只有一处**对外发起连接：启动时探测 `127.0.0.1` 的端口上是不是已经有一个自己在跑。没有对任何外部域名的请求
- 不收集、不上报、不埋点、不需要账号
- 读 WorkBuddy 会话时是只读打开，不改不删
- 缓存文件（`data/_index.json`）和导入的数据（`data/sources/`）都在本地，且已加入 `.gitignore`

### 它在本机存了什么

除了原始会话记录（那本来就是 WorkBuddy 的），这个程序自己会生成一个索引文件 `data/_index.json`，
**里面装着会话标题、文件路径，以及每个会话约 1.2 KB 的正文片段**（用于搜索）。

| 存了什么 | 为什么需要 | 敏感程度 |
|---|---|---|
| 会话标题、时间戳 | 显示列表 | 低 |
| 动过的文件名 | 空间视图 | 低 |
| 正文片段（提问 + 助手回复各若干条） | 搜索正文 | **中 —— 可能含你自己写进去的私人内容** |

**这个文件绝不能发给别人。** 打包脚本（`release/build_release.py`）已经把 `_index.json`
写进排除清单，并在打包后自动扫一遍全包确认没有它 —— 但如果你手工复制文件夹，记得先删掉它。

想清空索引：删掉 `data/_index.json`，下次启动会重建。

### 锁定用的 `_lock.json`

只有三段：`salt`（随机盐）、`check`（你的密码经 PBKDF2 之后的结果）、`locked`（被锁节点的 id 列表）。
**没有密码本身** —— 所以别人拿到它也反推不出你的密码。但 `locked` 那份列表会暴露你锁了哪些路径，
一样不该外传。它已在 `.gitignore` 里，每台机器各一份。

想自己核实，搜一遍就行：

```bash
grep -n "urllib\|requests\|http" live_server.py
```

你会看到唯一一处 `urlopen`，地址是 `http://127.0.0.1:%d/api/ping`。

## 已知限制

老实说清楚，免得你用着觉得被骗：

| 问题 | 状态 |
|---|---|
| **只在 Windows 上实测过** | 代码按跨平台写（只用标准库、剪贴板分三平台处理），但 macOS / Linux 我没条件真机验证。CSV 那条路应该没问题；读 WorkBuddy 会话在非 Windows 上能不能正确定位到 `~/.workbuddy/projects`，未经验证 |
| 珠子多的时候可能重叠 | 靠固定摆位规避，没有通用防重叠算法 |
| 长名字会截断成 `...` | 有截断，没做自适应缩放 |
| 只支持 CSV 和 WorkBuddy 会话两种数据源 | 加新类型需要写代码 |
| 没有导出功能 | 只能用截图 |
| **锁只挡得住本程序的 AI 接口** | 它挡的是 MCP 和搜索，**不是文件系统权限**。别的软件（编辑器、备份、同步盘）照样能读那些文件；要真正拦住，得靠系统账户权限 |
| 中文以外的界面 | 暂时只有中文界面 |
| **没有常驻的数据源切换下拉框** | 现在切数据源要么改网址参数，要么在页面里导入新 CSV（导入后会自动切过去）；右键菜单里有「新增数据源 · CSV / 文件夹」两个入口 |
| **搜索只搜标题、文件名和正文片段** | 正文索引存每个会话约 1.2 KB（用户提问 + 助手回复），**不是全文索引** —— 搜不到没被采样到的段落 |
| **每个会话的文件清单最多留 8 个** | 索引层为了控制体积做的截断，改动多的会话会漏掉部分文件 |
| **不同视图的圆大小口径不完全一致** | 步骤按耗时、回合按步数、库按总量，跨层比较大小不严谨 |
| **AI 定位要求网页正开着** | 网页关着时 `workflow_show` 会明确说不跳转，不会假装成功 |
